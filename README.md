## Project Overview

This project is a cloud-based maintenance service system hosted on Microsoft Azure using Infrastructure as a Service (IaaS).

The purpose of this project is to provide an online platform where users can report maintenance issues such as electrical faults, plumbing problems, and facility maintenance requests.

The server is hosted on an Ubuntu Linux virtual machine and configured manually using command-line tools.
